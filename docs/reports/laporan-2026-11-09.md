## 2. Pekerjaan yang Diselesaikan

### 2.1 Fix — Crash `Route [login] not defined`

**Gejala:** setiap guest membuka `/` mendapat HTTP 500 dengan stack trace di `routes/web.php:25`.

**Akar masalah:** terjadi **half-merge**. Commit `077282a` menambah login lokal (key `auth.sso.enabled`, `fortify.views=true`, `login.tsx`, dll.), lalu merge `b32d808` mengembalikan hampir semuanya **kecuali satu baris** di `web.php:25` yang tetap memanggil `route('login')` — padahal route `GET login` tidak terdaftar lagi.

**Perbaikan (restore ke mode local-login sesuai keputusan):**
- `config/auth.php` — tambah `'sso' => ['enabled' => env('AUTH_SSO_ENABLED', true)]`.
- `config/fortify.php` — `'views' => false` → `true` (mendaftarkan route `GET login`).
- `bootstrap/app.php` — `redirectGuestsTo` mengikuti flag SSO; tambah `redirectUsersTo(fn () => route('home'))`.
- `resources/js/pages/auth/login.tsx` + `tests/Feature/Auth/LocalLoginTest.php` — dipulihkan.

**Verifikasi:** `route:list --name=login` kini menampilkan `GET|HEAD login` + `POST login.store`; test auth hijau.

---

### 2.2 Fix — Duplicate Identifier `assignForm` (Wayfinder)

**Gejala:** `[BabelError] Identifier 'assignForm' has already been declared` di `resources/js/actions/App/Http/Controllers/WorkOrderController.ts` → mematahkan kompilasi modul sehingga `create.tsx`/`Edit.tsx` gagal.

**Akar masalah:** Wayfinder menamai export berdasar **nama method controller**. Route `work-orders.assign-form` → method `assignForm` menghasilkan `assignForm`; method `assign` (POST) dengan `--with-form` menghasilkan companion `assign`+`Form` = `assignForm` juga → tabrakan.

**Perbaikan (di sumber, bukan file generated):**
- `app/Http/Controllers/WorkOrderController.php` — `assign()` → `assignSubmit()`.
- `routes/web.php` — action route diarahkan ke `assignSubmit` (nama & URL route tidak berubah).
- Regenerasi `php artisan wayfinder:generate --with-form`.

**Verifikasi:** tidak ada duplikat identifier; `assignForm` (GET) + `assignSubmit` (POST) koeksis; modul serve 200 bersih di Vite; error tsc turun 6 → 4.

---

### 2.3 Fitur — Layout Auth Khusus

**Gejala:** halaman login menampilkan sidebar dashboard di belakang form (tampilan rusak).

**Akar masalah:** resolver layout di `app.tsx` mengarahkan **semua** halaman ke `AppLayout`, termasuk `auth/login`.

**Perbaikan:**
- `app.tsx` — tambah cabang `case name.startsWith('auth/')` → `AuthSplitLayout`.
- `auth-split-layout.tsx` — ditulis ulang menjadi **split brand layout** memakai design token proyek: panel navy gelap (logo, headline, 3 kartu fitur) + panel form kartu di atas `bg-canvas`; responsif (panel disembunyikan di mobile).
- `pages/auth/login.tsx` — buang wrapper full-screen sendiri; form jadi kartu `rounded-2xl` murni.

**Verifikasi:** screenshot headless desktop 1440px (split navy + kartu, tanpa sidebar) dan mobile nyata 390px via CDP — `scrollWidth = innerWidth = clientWidth = 390` (**0 overflow horizontal**). Login POST tetap berfungsi.
